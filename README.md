# OPS-NC Homebrew tap

```
brew install ops-nc/tap/ytui
```

| Formula | Description |
|---|---|
| [`ytui`](Formula/ytui.rb) | Audio-first YouTube client for the terminal, light on RAM — [OPS-NC/YTui](https://github.com/OPS-NC/YTui) |

Works on macOS (Apple Silicon and Intel) and Linux (x86_64 and ARM64).
`Formula/ytui.rb` follows the latest YTui release automatically
(`.github/workflows/update-ytui.yml`, every 3 hours or on demand).

Upgrade: `brew update && brew upgrade ytui`.
